# Hi, I'm alzhmd

I build **Telegram bots, payment tooling and Persian-first web apps** — Python, TypeScript and Rust, with RTL and i18n done properly.

## Open-source projects

| Project | What it does | Stack |
|---|---|---|
| [**tg-channel-mover**](https://github.com/alzhmd/tg-channel-mover) | Copies a whole Telegram channel into another one — no "Forwarded from", albums, captions and buttons kept, Premium emoji preserved, links re-pointed, resumable. | Python · Telethon · python-telegram-bot |
| [**bolgram**](https://github.com/alzhmd/bolgram) | Card-to-card payment gateway with automatic confirmation from bank SMS (Persian, RTL). | TypeScript · Docker |
| [**zagros-shop**](https://github.com/alzhmd/zagros-shop) | Self-hosted Persian e-commerce shop — server-side rendered, HTMX, RTL. | Rust · Axum · PostgreSQL |
